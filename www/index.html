錄音自動分切

超過設定時長時，系統自動停止目前錄音並立刻啟動下一段，所有分段在做 AI 分析時會自動合併處理。設為 0 代表不自動分切（預設 60 分鐘）。

AI 逐字稿分段單位

AI 深度分析時，音檔會按此設定切段送 Gemini 轉錄，建議值 3–10 分鐘（預設 5 分鐘）。值越小段數越多、越精確，但 API 呼叫次數也越多。

啟用的模型

取消勾選的模型，不會出現在主畫面的模型下拉選單，也不會被智慧切換挑到。每一組至少要保留一個。已存的設定若剛好是被停用的模型，會自動改用同組第一個已啟用的。

工具呼叫（Function Calling）

讓 Gemini／Grok 在對話中自己呼叫工具（內建、本地技能、遠端 MCP），最多連續 6 輪。隨時可用 /mcp 你要做的事 強制使用。

遠端 MCP 伺服器

手機上只支援遠端（HTTP）MCP：優先 Streamable HTTP，舊版 SSE 為備援（在 App 內可能無法串流，建議用 Streamable HTTP 網址）。

本地技能

勾選＝讓 AI 在對話中可以呼叫。匯入技能檔案請同時選 skills.json 與對應的 .js 檔（可多選）；技能的新增、編輯、重播與刪除在「技能管理」或側邊欄「技能範本」。（Android 無法直接讀公開 Documents 資料夾，所以要用按鈕匯入。）

Context Caching（明確快取）

工具迴圈跑到指定輪數、且「系統提示＋工具宣告＋起始對話」夠長時，建立 Gemini 快取，之後每輪只送新增的內容（快取部分按快取價計費）。失敗會自動改送完整請求；迴圈結束會刪除快取。僅 Gemini。

以「/ap 指令」啟動的自主任務，會透過 uiautomator2（在 Termux 內安裝並啟動 atx-agent 服務）操控手機畫面完成任務。啟動後不需逐步確認，但以下雙重限制會強制中止，避免失控。

無障礙服務模式：不需要 Termux／atx-agent。需在系統「無障礙」手動開啟 NOVA 服務（Android 11 以上才有截圖功能）。只有你輸入 /ap 時才會操作手機。

首次使用請在 Termux 執行：pkg install python -y && pip install "setuptools<70.0.0" "uiautomator2<3.0" && python -m uiautomator2 init，這會安裝並啟動 atx-agent（監聽本機 7912 埠）。⚠️ uiautomator2 3.0 以後版本已移除 atx-agent 長駐服務，務必安裝 2.x 版本；同時新版 setuptools 移除了 pkg_resources 會導致安裝失敗，需一併降版。

用法：在對話框輸入「/ap 你要它做的任務」即可啟動自主任務。

執行中每一步都會即時顯示「正在執行：...」；達到最大回合數、單回合逾時，或 AI 判斷任務已完成／無法繼續時會自動停止。
